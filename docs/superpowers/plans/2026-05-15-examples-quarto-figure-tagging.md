# Examples Quarto Figure Tagging Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Quarto figure labels and captions to the Jupyter notebooks in `examples/` so their generated figures can be cross-referenced from the article.

**Architecture:** We will annotate the existing output-producing notebook cells with Quarto Jupyter cell options placed directly in the cell source. Each notebook will be handled independently, preserving the current computational code and only adding the minimum metadata and cell reshaping needed for figure-level labeling, captions, and grouped subcaptions where a single cell produces multiple visual panels.

**Tech Stack:** Quarto Jupyter cell options, Jupyter notebook `.ipynb` files, Python plotting output from Matplotlib and Seaborn, PowerShell for verification, Quarto CLI from `.venv\Scripts\quarto.exe`
